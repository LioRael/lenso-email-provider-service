# Issue tracker: GitHub

Issues and PRDs live in the central `LioRael/lenso` repository. Code pull
requests live in `LioRael/lenso-email-provider-service`.

Cross-repository pull requests use:

```text
Closes LioRael/lenso#<ticket-number>
```

Read the complete central ticket and blockers before changing tracker state.
Keep it open until the implementation pull request merges.
